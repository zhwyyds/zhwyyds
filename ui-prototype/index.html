📚 当前命名规范
Route A · 英文标准化命名
🎯 命名公式
[modifier_]+root
modifier → 时间/对比/维度修饰词（可选，可多个）
root → 词根组合（必填，至少1个）
示例：mtd_ord_amt = 本月(mtd) + 订单(ord) + 金额(amt)

⏱️ 常用修饰词
mtd→本月 (month-to-date)
ytd→本年 (year-to-date)
qtd→本季 (quarter-to-date)
cum→累计 (cumulative)
mom→环比 (month-over-month)
yoy→同比 (year-over-year)
lm→上月 (last month)
lysp→上年同期
day_avg→日均
ach_rte→达成率
📊 数据类型后缀
amt→金额 (amount)SUM类
cnt→计数 (count)COUNT类
rte→比率 (rate)百分比
stock→存量时点值
avg→均值AVG类
val→数值通用
✅ 命名规则： 1. 全小写，下划线分隔 · 2. 词根优先，修饰词前缀 · 3. 禁止拼音（如 yuan_gong → employee） · 4. 禁止缩写歧义（如 cnt 不写为 c） · 5. 同名同义：同一概念全局唯一命名 · 6. 英文名 = 完整单词，缩写名 = modifier_root 组合
