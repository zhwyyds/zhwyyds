01 系统概述

指标卡包系统是家居卖场租赁数据治理项目的可视化前端，将治理后的指标以 RPG 装备卡牌的形式呈现，通过卡包堆叠 + 抽卡交互的方式浏览和管理指标。

设计目标

  • 将指标从冰冷的表格行转化为直观、可交互的视觉实体
  • 通过颜色、边框、纹样三个维度同时编码指标的分类信息
  • 以卡包隐喻管理大量指标：堆叠存放 → 查阅预览 → 抽出细览 → 收回归位
  • 支持白板模式（快速浏览）和网格视图（全局总览）两种辅助视图

02 设计体系总览

系统采用三维编码策略：主题→主色、类型→边框样式、评分→稀有度边框，再加上二级分类→纹样图案，形成四维视觉差异化。

四维编码模型：每张指标卡同时携带 4 个视觉信号 —— 主色（你在看哪个业务域）、边框样式（这是哪种计算层级的指标）、稀有度光环（这个指标治理得好不好）、纹样图案（这个指标属于哪个分析类别）。用户一眼即可识别卡片的完整身份。
维度 CSS 属性 数据字段 取值数 视觉效果
主题（一级分类） data-theme theme 14 主色 accent / accent-deep / accent-soft / glow
指标类型 data-type type 3 边框层数 + 四角饰大小 + 类型徽章
评分等级 data-rarity score → rarity 4 边框配色 + 辉光强度 + 流动动画
二级分类 data-cat cat 7 纹样图案（repeating/radial/conic-gradient）

CSS 变量驱动机制

每个主题通过属性选择器在 .frame 和 .card 上同时设置 4 个 CSS 变量：

/* 示例：交易主题 */
[data-theme="sale"] {
  --accent:      oklch(78% 0.14 55);   /* 主色：标题、图标、徽章 */
  --accent-deep: oklch(54% 0.13 50);   /* 深色：按钮、边框下层 */
  --accent-soft: oklch(90% 0.09 60);   /* 浅色：标题文字、徽章文字 */
  --glow:        0 0 14px oklch(78% 0.14 55 / 0.35); /* 辉光阴影 */
}
注意：data-theme 必须同时设在 .frame 和 .card 上。因为 .frame 的 box-shadow 边框和 .card 的内部元素都需要访问 --accent 系变量，仅设在子级会导致父级边框拿不到变量值。

04 指标类型边框（3 类型）

通过边框层数、四角饰大小和类型徽章样式区分原子/衍生/复合三种指标计算层级。

类型 中文名 定义 边框层数 四角饰 徽章样式
atomic 原子 原始采集，无计算 2 层（1.5px + 4px） 标准 26×26px solid 实线边框
derived 衍生 由原子指标计算得出 3 层（1.5 + 4 + 5.5px）+ 虚线点划环 标准 26×26px dashed 虚线边框
composite 复合 多源聚合，最复杂 3 层（2 + 5 + 7px）+ 外辉光 加大 32×32px，4px 粗线 double 双线边框

衍生类型虚线环

衍生指标在 .frame::before 上叠加 outline: 1px dashed 点划环，表示"由其他指标衍生而来"的语义：

.frame[data-type="derived"]::before {
  box-shadow: inset 0 0 0 1px oklch(0% 0 0 / 0.18);
  outline: 1px dashed color-mix(in oklch, var(--accent) 70%, transparent);
  outline-offset: -6px;
}

复合类型加厚边框

复合指标使用最厚的 3 层 box-shadow + 外辉光 + 加大四角饰，视觉上传达"信息密度最高"：

.frame[data-type="composite"] {
  box-shadow:
    0 0 0 2px var(--frame-1),
    0 0 0 5px var(--frame-2),
    0 0 0 7px color-mix(in oklch, var(--accent) 45%, transparent),
    0 28px 60px oklch(0% 0 0 / 0.6),
    0 0 40px color-mix(in oklch, var(--accent) 50%, transparent);
}

05 稀有度评级（4 等级）

评分（0-100）映射为 4 档稀有度，控制边框配色、辉光强度和动画效果。映射关系为：≥90 优秀、≥75 良好、≥60 合格、<60 待改进。

稀有度 评分区间 边框色调 辉光 动画 徽章文字
excellent ≥ 90 金色 (hue 82) 强辉光 纹样流动 (14s) ★ 优秀
good 75 - 89 紫色 (hue 300) 中辉光 无 ★ 良好
pass 60 - 74 蓝色 (hue 250) 弱辉光 无 ★ 合格
poor < 60 灰色 (低彩度) 最弱 无 ★ 待改进

评分到稀有度的映射函数

const RARITIES = [
  { min: 90, key: 'excellent', name: '优秀' },
  { min: 75, key: 'good',      name: '良好' },
  { min: 60, key: 'pass',      name: '合格' },
  { min:  0, key: 'poor',      name: '待改进' }
];
function rarityOf(score) {
  return RARITIES.find(r => score >= r.min);
}

传说级流动纹样

优秀（excellent）评级的卡片，其纹样图案会以 14 秒为周期缓慢流动，营造"传说品质"的动态质感：

.frame[data-rarity="excellent"]::before {
  animation: patroll 14s linear infinite;
}
@keyframes patroll {
  from { background-position: 0 0; }
  to   { background-position: 48px 0; }
}

卡片有三种交互状态：默认（卡包中）、查阅（悬停预览）、抽出（点击锁定展示），通过 JS 状态变量和 CSS 类名协同管理。

状态变量

let activeIdx = -1;      // 当前抽出的卡（-1 = 无）
let hoverIdx = -1;       // 当前查阅的卡（-1 = 无）
let drawing = false;     // 动画进行中锁，防连点

关键约束

  • 查阅不阻塞：peek 时卡片上抬 240px 完全脱离卡堆，其余卡仍可被 hover
  • 抽出时禁查阅：peek() 在 activeIdx >= 0 时直接 return，避免误触发
  • 动画锁：drawing = true 在动画期间阻止新操作，580ms 后释放
  • 三条收回路径：点击中央卡片本身 / 点击遮罩 / 点击底部收回按钮

飞向视口中央的计算

centerOffset() 使用 getBoundingClientRect() 计算卡片当前到视口中心的位移，写入 CSS 变量供动画使用：

function centerOffset(el, dy = 0, scale = 1.3) {
  const r = el.getBoundingClientRect();
  const vw = document.documentElement.clientWidth;
  const vh = document.documentElement.clientHeight;
  const cx = vw / 2 - (r.left + r.width / 2);
  const cy = vh / 2 - (r.top + r.height / 2) + dy;
  el.style.setProperty('--fly-x', cx + 'px');
  el.style.setProperty('--fly-y', cy + 'px');
  el.style.setProperty('--fly-scale', scale);
}

09 视图模式

系统支持三种视图模式：正常模式（扇形卡包）、白板模式（窄条快速浏览）、网格视图（全部取出总览）。

模式 触发 卡片尺寸 显示内容 交互
正常模式 默认 360×540px 全部 18 字段 扇形堆叠 + peek/draw
白板模式 btn-mode 按钮 288×64px 窄条 仅名称 + 编号 + 稀有度 + 类型 + 主题色竖条 堆叠 + peek(上抬 160px) + draw(恢复完整卡)
网格视图 btn-all 按钮 206×148px 小卡 仅标题 + 编号 + 稀有度 + 类型 + 主题色竖条 4 列网格 + hover 高亮 + click(退出网格→draw)

白板模式

白板模式通过 .pack.board-mode 类名切换，隐藏除 .title-zone、.rare-badge、.type-badge、.card-accent 外的所有子元素：

.pack.board-mode .card > *:not(.title-zone):not(.rare-badge):not(.card-accent):not(.type-badge) {
  display: none;
}

抽出时（.active-lock）自动恢复完整卡片尺寸和全部内容，确保查看详情不受影响。

网格视图

网格视图将卡包转为 CSS Grid 4 列布局，每张卡变为 222×148px 小卡，在居中浮窗中整齐排列：

.pack.grid-view {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 18px;
  width: 960px;
}
.pack.grid-view .frame {
  position: static;
  transform: none !important;  /* 覆盖扇形 transform */
}

10 卡包堆叠几何

14 张卡片以扇形堆叠在卡包中，上层卡压下层卡左边，底部对齐，绕左下角旋转。

堆叠参数计算

const n = METRICS.length;  // 14

// 扇形角度：i=0 直立(0°)，i=13 最倾(-18°)
const baseAngle = -18 * i / (n - 1);

// 固定伪随机错乱（用质数取模保证稳定）
const jitterA = ((i * 37) % 9) - 4;   // -4° ~ +4°
const jitterX = ((i * 53) % 13) - 6;  // -6px ~ +6px
const jitterY = ((i * 29) % 7) - 3;   // -3px ~ +3px

const fanDeg = baseAngle + jitterA;
const stackX = (n - 1 - i) * 34 + jitterX;  // i=0 最右(442px) → i=13 最左(0)
const stackY = jitterY;                      // 底部对齐，仅微抖

CSS transform 组装

.frame {
  transform-origin: 0% 100%;  /* 绕左下角旋转 */
  transform: translate(var(--stack-x), var(--stack-y))
             rotate(var(--fan-deg))
             scale(0.97);
}
设计意图：底部对齐 + 绕左下角旋转 = 像手持扑克牌扇形展开的真实物理感。上层卡（z-index 更高）压住下层卡的左边，每张卡从右侧露出 34px 让下层卡可被识别和点击。

11 动画系统

系统包含 5 组关键帧动画，覆盖抽出、收回、闪光、纹样流动和无障碍降级。

动画名 触发场景 时长 关键帧数 效果描述
lockpop 抽出 draw 0.7s 6 蓄力下压 → 倾斜爆抽 → 飞向中央 → 超调回弹 → 稳定
lockback 收回 putBack 0.55s 4 中央位置 → 反向倾斜 → 飞回路径 → 归位扇形
flash 抽出时光效 0.6s 4 accent 色光带 105° 横切卡面，左→右扫过
patroll 优秀级纹样 14s 2 纹样 background-position 缓慢右移
reduced-motion 无障碍降级 — — 禁用所有 transition 和 animation

抽出动画 lockpop 关键帧

@keyframes lockpop {
  0%   { /* 卡包原位：扇形角度 + scale 0.97 */ }
  15%  { /* 蓄力：下压 22px + 歪斜 +8° + 缩小 0.94 */ }
  35%  { /* 爆抽：飞至 30% 处 + 反向倾斜 -12° + 放大 1.05 */ }
  55%  { /* 超调：飞到位 + 倾斜 6° + 放大 1.42（超调 +0.12）*/ }
  75%  { /* 回弹：微回 + 倾斜 -2° + 放大 1.34 */ }
  100% { /* 稳定：归正 0° + 放大 1.3 */ }
}

无障碍降级

@media (prefers-reduced-motion: reduce) {
  .frame { transition: none !important; }
  .frame::before, .frame::after { animation: none !important; }
}

扩展新指标卡

在 METRICS 数组末尾添加一条记录即可，系统自动渲染：

{
  code: 'M_SALE_002',
  name: '季度销售额',
  theme: 'sale',           # 14 主题之一
  cat: 'overview',          # 7 分类之一
  type: 'derived',          # atomic / derived / composite
  score: 85,               # 0-100，自动映射稀有度
  unit: '元',
  cycle: '季度',
  precision: '两位小数',
  table: 'dwd_sale_order_q',
  dims: ['时间', '机构', '渠道'],
  desc: '自然季度内已完成订单的销售总金额。',
  formula: 'SUM(order_amount) WHERE quarter=当前季度',
  source: '订单系统',
  tech: "SUM(sale_amt) WHERE stat_quarter=当前季度",
  owner: '交易分析部',
  ver: 'v1.0.0',
  verNote: '2026-08-06 · 初版'
}
自动联动：添加记录后，系统自动根据 theme 渲染主题色、根据 type 渲染边框样式、根据 score 映射稀有度、根据 cat 渲染纹样和图标，无需手动配置任何 CSS。
