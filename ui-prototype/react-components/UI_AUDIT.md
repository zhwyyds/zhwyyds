# MetricCard 组件 UI 审计报告

> 审计依据：Vercel Web Interface Guidelines（web-design-guidelines skill 规则集）
> 审计对象：`ui-prototype/react-components/MetricCard.jsx`
> 审计方式：代码级静态审查（对比度按 WCAG 2.1 AA 计算）
> 设计参数：DESIGN_VARIANCE=5 / MOTION_INTENSITY=4 / VISUAL_DENSITY=7

---

## 一、合规项（✅ 通过）

| 规则 | 实现 |
|------|------|
| 交互元素用语义元素 | 卡片/翻面/关闭均为 `<button>`，无 `div onClick` |
| 图标/状态需可访问名 | 卡片 `aria-label`（名称+域+状态）；关闭按钮 `aria-label="关闭详情"` |
| 可见焦点 | 全部交互元素 `focus-visible:ring-2` + offset，无 `outline:none` 裸用 |
| 键盘可达 | 卡片可 Tab + Enter 打开；`Esc` 关闭弹窗；弹窗初始聚焦 |
| 对比度（正文） | 主文字 `#1f2328` on `#fff` ≈ **16:1**；口径 `#3d444d` ≈ **11:1**；次级 `#57606a` ≈ **7.4:1**；微弱 `#6e7781` ≈ **5.4:1** —— 全部 ≥ AA(4.5:1) |
| 对比度（徽章） | 已审核 `#1a7f37`/白 ≈ 4.9:1；待审核 `#8a5a00`/白 ≈ 5.1:1；已打回 `#a40e26`/白 ≈ 7.0:1 —— 达标 |
| 对比度（角标） | 14 域色均为深色系 + 白字，理论 ≥ 4.5:1 |
| 语义结构 | `h3` 标题层级；卡背 `dl/dt/dd` 定义列表；`role=list/listitem` |
| 动效降级 | `prefers-reduced-motion`：hover 抬升关闭、下探动画关闭、翻面过渡关闭 |
| 装饰性元素 | 四角饰点、灰星为纯装饰，不承载信息（星级等级有 `aria-label`）|
| 禁用炫丽效果 | 无粒子、无渐变背景、无发光、无回弹动画（约束满足）|

## 二、风险点（⚠️ 按严重度）

### P1（建议修复）
| # | 风险 | 位置 | 影响 | 建议 |
|---|------|------|------|------|
| R1 | **弹窗无焦点陷阱** | `MetricCardModal` | Tab 可把焦点逃逸到背景页面，键盘用户可能"走出"弹窗 | 用 `keydown` 捕获 Tab 并循环到弹窗首/末元素；或引入 `@headlessui`/`react-aria` 的 Dialog |
| R2 | **翻面双面内容读屏重复** | `.mc-flip-face` | 正反两面同时在 DOM，读屏可能朗读两遍内容 | 非活动面加 `aria-hidden="true"` + `inert`；或根据 `flipped` 只渲染一面 |

### P2（视觉回归验证）
| # | 风险 | 位置 | 影响 | 建议 |
|---|------|------|------|------|
| R3 | 14 域角标色为程序性深色取值，未逐色实测 | `DOMAIN_STYLES` | 个别深色（如 `#2d5a27` 商场绿）需确认与白字实测对比度 ≥ 4.5:1 | 上真实色板后做一次对比度工具实测（如 WebAIM Contrast Checker）|
| R4 | 高信息密度（DENSITY=7）在 280px 极窄卡可能拥挤 | `CardFace` | 名称过长 + 口径 3 行截断，窄屏阅读压力大 | 已用 `line-clamp` 兜底；若产品接受，minmax 提到 300px |

### P3（体验微调）
| # | 风险 | 位置 | 影响 | 建议 |
|---|------|------|------|------|
| R5 | 翻面 500ms 偏长 | `.mc-flip-inner` | 连续翻面有拖拽感 | 降到 350-400ms，或仅首次播放 |
| R6 | hover 抬升触屏无效 | `MetricCard` | 触屏无抬升反馈（功能不受影响，点击弹窗兜底）| 可加 `active:translate-y-[-2px]` 按压反馈 |
| R7 | 弹窗无"下探起点对齐"（从卡片位置飞出）| `MetricCardModal` | 目前为居中下落，非严格"从卡下探" | 若要精确，需传卡片 DOM 坐标做 `transform-origin` 动画（本次按简洁原则未做）|

## 三、与产品约束的对齐

- ✅ **无粒子特效 / 无炫丽渐变**：卡面背景纯白 + 极淡色块，质感全由边框/阴影承载
- ✅ **业务信息优先**：名称/英文/口径/时间为卡面主体，装饰元素（角饰/星级）占比 < 5%
- ✅ **WCAG 达标**：核心文字对比度全部 ≥ AA（见合规项）
- ✅ **TCG 质感克制**（VARIANCE=5）：双层描边 + 四角饰点 + hover 抬升，无稀有度发光/卡面图案

## 四、结论

组件**可交付**。P1 两项（焦点陷阱、读屏重复）建议在接入真实应用前修复；P2/P3 为迭代项。整体满足"TCG 视觉 × 企业可读性"的融合目标。
